# Documentación y auditoría

Esta carpeta está reservada para la matriz de exploración de la Evidencia 2, la trazabilidad de los prompts ROCAS y los registros de verificación pedagógica y técnica del OVA de lectura crítica de grado noveno.

La entrega académica de la Evidencia 3 exige un archivo `index.html` único y autocontenido en la raíz, que funcione sin internet con CSS y JavaScript integrados. La publicación en GitHub Pages será complementaria. Los resultados de pruebas no deben describirse como resultados obtenidos con estudiantes.
