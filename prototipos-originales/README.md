# Prototipos originales de la Evidencia 2

Esta carpeta conservará las versiones originales de los tres recursos exploratorios de Lengua Castellana, noveno grado, Institución Educativa San José del Pantano:

1. `entre-lineas.html` — prototipo originalmente llamado `index.html`, reconocimiento de ideas principales.
2. `Inferencias_9.html` — laboratorio de pistas e inferencias.
3. `El_Laboratorio_del_Argumento_9.html` — clasificación de tesis, razones y evidencias.

Los archivos se incorporarán cuando el usuario proporcione los originales. No confundir las pruebas exploratorias con resultados empíricos de estudiantes. El OVA integrado se entregará por separado como `index.html` en la raíz del repositorio.
